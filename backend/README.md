    🛠️ Sistema de Gestão para Oficina / Metalúrgica

Este projeto foi desenvolvido a partir de uma necessidade real do ambiente de trabalho, ao mesmo tempo em que está sendo utilizado como projeto de estudo e prática em Java e Spring Boot.

A ideia é criar uma base simples e funcional para organização de informações de uma oficina/metalúrgica, evoluindo o sistema conforme o aprendizado e novas necessidades surgem.

    🎯 Objetivo

Desenvolver uma API REST para gestão básica de uma oficina, começando pelo cadastro de clientes, permitindo:

Cadastro de clientes

Listagem de clientes

Estrutura preparada para futuras funcionalidades

O projeto foi iniciado de forma simples, com foco em entender o funcionamento do Spring Boot, organização do código e boas práticas.

    🚀 Tecnologias Utilizadas

Java

Spring Boot

Spring Web

Spring Data JPA

H2 Database (ambiente de desenvolvimento)

Maven

VS Code

Git e GitHub
